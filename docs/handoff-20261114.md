## 2. Permissions on this machine (learned today)

- `git push origin HEAD:main` for code is refused by the session's permission check until Ahmed says «ادمج» for that change.
  Routine that worked all day: branch `claude/<topic>-20261114` → push the branch → CI green → dry run → tell him the result
  → he says «نعم، ادمج» → push to `main` → deploy / sync → check live → write `docs/current-state.md`.
- CI is watched without a token: `https://api.github.com/repos/omanvilla/habib-crm/commits/<sha>/check-runs` (failing test
  names are in the check run's annotations).
- Supabase through the MCP tools. SQL is applied with `apply_migration` fetching the committed file (see the old handoff).
  A forward file can be tried first inside `begin; … rollback;` with `execute_sql`.
- Ahmed's Chrome (Claude in Chrome) may be used when he says so. Never type card or password data; a form that sets
  something permanent (currency) is left for him to submit.
- Perl one-liners edit Arabic text fine when the script is a file with `use utf8; use open qw(:std :utf8);`, but `\n` and
  `\s` written inside a replacement string come out as real characters: write those lines with the Edit tool.
