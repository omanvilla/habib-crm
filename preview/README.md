# معاينة CRM المعزولة — 2026-09-30

هذه معاينة واجهة ببيانات اصطناعية في ذاكرة المتصفح. ليست Supabase staging وليست جلسات المالك أو هديل أو مرام الفعلية. لا تثبت RLS ولا دوال الخادم ولا إرسال Meta.

## التشغيل

من نسخة المستودع على الفرع `codex/role-workflows-ui-preview-20260930`، مع Node 22 وGit:

```sh
node preview/serve.cjs
```

افتح http://127.0.0.1:4173/after/owner/ ثم استخدم روابط «قبل/بعد، مسقط، بركاء» في شريط المعاينة. نسخة «قبل» تقرأ الملفات من commit `e9bd1d54e0781cd9445c9d7ad5ac2f004749e961` عبر Git، لذلك يجب أن يتوفر هذا commit محلياً.

للاختبارات:

```sh
node --test tests/*.test.cjs
node tests/security-regressions.cjs
npm install --no-save --package-lock=false playwright@1.55.0
npx playwright install --with-deps chromium
node tests/preview-browser.cjs
```

الصور وCSV وملف `browser-report.json` ومعرض صور `index.html` تحفظ في `preview-results/`، وتنشر كمرفق Actions فقط. افتح ملف المعرض بعد فك المرفق لعرض المقارنة محلياً.

## العزل والتنظيف

- الخادم يستمع على 127.0.0.1، ويقدم ملفات مسموحة فقط، ويرفض كل POST/PUT/DELETE بـ405. لا يحتوي عميل شبكة صادر أو جدولة أو موصل Supabase.
- نستبدل SDK الإنتاج ببيانات اصطناعية، ونمنع الاتصالات الخارجية وSDK ميتا باستخدام CSP؛ واختبار Chromium يمنع أي طلب خارج 127.0.0.1 أيضاً.
- إرسال الرسائل وتنزيل مرفقات خارجية وAI والمزامنة والأتمتة وتغيير كلمات المرور مرفوضة في fixture. لا توجد مفاتيح إنتاج ولا حسابات عملاء حقيقيين في المعاينة.
- الإضافة والتعديل في الذاكرة فقط. إعادة تحميل الصفحة تعيد البيانات الأصلية، وإغلاق BrowserContext يحذف جلسة الاختبار. زر «بدء جلسة معاينة جديدة» يمسح حالة الخروج الاصطناعية لهذا المسار فقط.
- لا تستخدم هذه المحاكاة لاختبار تنفيذ الزيارة الذري أو Storage أو صلاحيات الموظفين على API/RPC. لا تجعل fixture backend عنوان الإنتاج.
- أدوار manager/viewer المتاحة في fixture افتراضية للتطوير ولم تختبر كأدوار فعلية مستخدمة.
